# Code of conduct

Be decent. Argue with the work, not the person.

Specifically: assume the other person read the code before commenting, say what
you measured rather than what you assume, and accept a correction the way you
would want yours accepted. Disagreement about a technical decision is the point
of a review and is always welcome. Contempt is not.

Harassment, personal attacks, and unwelcome attention are not tolerated, in
issues, pull requests, commit messages or anywhere else this project is
discussed.

If something here is not decent, report it privately through GitHub's report
feature or by opening a security advisory, which is private. Maintainers will
act, and will tell you what they did.
