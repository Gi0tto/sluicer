### Fixed

- The summary's title kept the site's name after a separator whenever the page did not declare that name ("Personal Training - UT RecSports"), and took a business's name or a description written into `headline` over the title the page shows. Of the titles a page declares, the one its `<h1>` heading shows is now the title, cut where the heading ends; the answer is still the declared text, and with no such heading nothing changes.
- `--visible` took a box whose class says there is no byline ("no-byline"), or the page's `<body>` itself, for a byline and read the first capitalised words in it as the author, and took the "By" line on another article's card, inside its link, for the page's own. None of them is read as the author now.
- `--visible` passed over every byline on a page whose `<body>` carries a class such as "has-share-buttons", which WordPress writes on posts, since it read the body's classes as another voice's box. A byline is now judged by the boxes round it up to the body, and a customer's testimonial is one of them, whose signature is not the author.
- `--visible` passed over a byline in an article's own `<footer>`, which HTML says holds who wrote it, as if it were the page's footer. It is read now; the page's footer is still passed over.
- `--visible` read no author from a link marked `rel="author"` holding one word, a handle or a first name ("MixmasterFred", "Lauren"), since a name was asked for two. The link says whose it is, so its one word is now the author, never a label such as "Admin" or "Staff".
